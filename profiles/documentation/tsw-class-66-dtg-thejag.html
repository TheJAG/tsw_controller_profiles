Class 66

Cab setup

  • Reverser handle in (PARK BRK)
  • Start engine (right throttle button), wait for it to run
  • Check AWS/TPWS and DSD fuse lights are out
  • Headlights to Day running
  • Release the parking brake (RUD TRIM right)
  • Train brake to Apply until the brake pipe is charged

Cleared to depart

  • Check the signal
  • Reverser to Forward
  • Loco brake to Release
  • Train brake to Release, wait for the pipe to charge
  • Throttle to 1, notch up slowly with the heavy train
  • Acknowledge AWS with the gear lever
