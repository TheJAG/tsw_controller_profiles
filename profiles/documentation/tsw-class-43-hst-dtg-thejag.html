Class 43 HST

Cab setup

  • Master key in (PARK BRK)
  • Reverser from Engine off to Neutral
  • Start engine (right throttle button), wait for it to run
  • Check AWS and DSD isolation lights are out
  • Headlights to Day
  • Open doors

Cleared to depart

  • Close doors, wait for the guard buzzer
  • Check the signal
  • Reverser to Forward
  • Brake to Running
  • Power to 1, notch up as speed rises
  • Acknowledge AWS with the gear lever
