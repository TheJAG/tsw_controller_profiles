NS ICMm

Cab setup

  • Insert master key (PARK BRK)
  • Pull the brake key (right throttle button)
  • Mode selector to Driving (flap lever)
  • Train voltage supply on, compressor to auto
  • Set headlights
  • Open doors

Cleared to depart

  • Close doors
  • Check signal and ATB
  • Set reverser to forward
  • Train brake to Running
  • Apply power
