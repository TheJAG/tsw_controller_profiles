ES 64 U2

Cab setup

  • Battery on in the cab, parking brake released
  • Richtungsschalter from Off (the key position) to Neutral
  • RUD TRIM left raises the pantograph, right closes the Hauptschalter
  • SiFa and PZB on (aux squares), PZB mode and brake selector set in the cab
  • Lights (AUTO BRK)
  • AFB on (PARK BRK up) if you drive with the speed setter

Cleared to depart

  • Check the signal and PZB
  • Richtungsschalter to Forward
  • Führerbremsventil to Running, wait for the brakes to release
  • Fahrschalter towards Max, or set the AFB speed on the flap lever
  • Acknowledge SiFa with the gear lever, PZB with the ENG switches
  • Brake: Führerbremsventil in steps; the E-brake lever stays in the cab
