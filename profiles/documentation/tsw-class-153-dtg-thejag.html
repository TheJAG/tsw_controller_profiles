Class 153

Cab setup

  • Master switch on (PARK BRK)
  • Start engine
  • Reverser to neutral
  • Check AWS and DVD breakers are normal
  • Headlights to day
  • Open doors

Cleared to depart

  • Close doors
  • Wait for guard buzzer
  • Check signal
  • Reverser to forward
  • Release brake
  • Apply power
