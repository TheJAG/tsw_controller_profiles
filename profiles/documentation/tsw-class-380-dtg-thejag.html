Class 380

Cab setup

  • Master key in (PARK BRK)
  • Pantograph up (right throttle button), wait for line volts
  • Direction switch to Neutral
  • TPWS/AWS and DVD isolation off (aux squares): a service starts with both isolated
  • Exterior lights to Day
  • Open doors (RUD TRIM)

Cleared to depart

  • Close doors, wait for the guard bell
  • Check the signal, DRA off
  • Direction switch to Forward
  • Handle from Max brake through Off into power
  • Pull further as speed rises
  • Acknowledge AWS with the gear lever
