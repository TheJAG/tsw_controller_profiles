Class 31

Cab setup

  • Master key and brake key in (PARK BRK up), battery on
  • Reverser to Engine only, start the engine (right throttle button)
  • AWS isolation light out, DSD breaker on
  • Marker lights on (AUTO BRK)
  • Release the handbrake in the cab
  • Train brake to Full service until the pipe is charged

Cleared to depart

  • Check the signal
  • Reverser to Forward
  • Loco brake to Release (flap lever away)
  • Train brake to Running, wait for the pipe to charge
  • Power controller notch by notch; the TCA walks one gate per send
  • Acknowledge AWS with the gear lever
  • Power controller to Off before moving the reverser back
