Class 87

Cab setup

  • Master key and brake key in (PARK BRK)
  • Pantograph up (right throttle button), wait for line volts
  • Check AWS isolation and DSD breaker lights are out
  • Lights to Head + markers, tail lights off
  • Release the parking brake (RUD TRIM right)
  • Train brake to Full service; service zone is continuous between 1st application and Full service

Cleared to depart

  • Doors closed, wait for the guard buzzer
  • Check the signal
  • Reverser to Forward (Reverse needs the lock button in the cab)
  • Train brake to Running, loco brake released
  • Power controller to Notch up, back to Hold at the wanted tap; Run down / Notch down to shed power
  • Acknowledge AWS with the gear lever
