Class 170

Cab setup

  • Master key in (PARK BRK)
  • Start engine (right throttle button)
  • Reverser to Neutral
  • Check AWS and DVD isolation lights are out
  • Headlights to Day
  • Open doors (RUD TRIM)

Cleared to depart

  • Close doors, wait for the guard buzzer
  • Check the signal
  • Reverser to Forward
  • Handle from B3 through Idle to P1
  • Notch up to P7 as speed rises
  • Acknowledge AWS with the gear lever
