British Rail · Just Trains · TCA Quadrant Airbus

Class 101

Cab setup

  • PARK BRK up: main switch on and AWS change-end key in
  • Start the engines (right throttle button for the front engine; the rear engine button is in the cab)
  • Reverser to Forward; the gear selector only moves then
  • Check the AWS and deadman isolation lights are out
  • Marker lights to White
  • Open doors (RUD TRIM)

Cleared to depart

  • Close doors, wait for the guard buzzer (round aux)
  • Check the signal
  • Gear selector to 1st (nearest), vacuum brake to Released
  • Throttle up to Full; change up through 2nd, 3rd and 4th with the throttle closed
  • Acknowledge AWS with the gear lever
  • Brake: throttle to Idling, gear to Neutral, vacuum brake into the apply zone; Lap holds the application
