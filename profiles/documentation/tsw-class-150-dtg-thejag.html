Class 150

Cab setup

  • Master key on (PARK BRK)
  • Start engine (right throttle button)
  • Reverser to Neutral
  • Check AWS/TPWS and DSD isolation lights are out
  • Headlights to Day
  • Open doors (RUD TRIM)

Cleared to depart

  • Close doors, wait for the guard buzzer
  • Check the signal
  • Reverser to Forward
  • Brake to Release
  • Throttle to 1, notch up as the gears change
  • Acknowledge AWS with the gear lever
