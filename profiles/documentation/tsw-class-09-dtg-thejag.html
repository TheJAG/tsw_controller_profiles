Class 09

Cab setup

  • PARK BRK up: master key On; battery and parking brake in the cab
  • Start the engine (right throttle button)
  • Reverser from Off to Forward: the power handle only moves then
  • Lights to Markers
  • Loco brake at Full, vacuum brake at Full (parked)

Cleared to depart

  • Check the signal and the shunter
  • Vacuum brake to Running, loco brake to Release
  • Power handle 1 to 4 (only with the reverser in Forward)
  • Deadman: acknowledge with the gear lever if the game asks
  • Brake: power Off, vacuum brake towards Full, or the loco brake light engine
  • Change direction: power Off first, then the reverser
