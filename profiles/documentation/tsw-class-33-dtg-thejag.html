Class 33

Cab setup

  • PARK BRK up: master key in; brake selector and timing switch in the cab
  • Start the engine (right throttle button): the power handle only moves with it running
  • Reverser from Off through Engine only to Forward
  • Check the AWS isolation light is out
  • Lights to A markers + headlight
  • Loco brake at Full, train brake at Full (parked)

Cleared to depart

  • Check the signal; release the handbrake in the cab
  • Train brake to Running, loco brake to Release
  • Power handle to On, then into the power zone
  • Acknowledge AWS with the gear lever
  • Brake: power Off, train brake towards Full; Emergency at the far end
  • Shut down: the Neutral position of the brake valve is in the cab
