BR 155

Cab setup

  • Battery on, compressors to Automatic in the cab
  • PARK BRK up: brake key in, frees reverser + brake valve
  • Pantograph up and Hauptschalter on in the cab
  • SiFa and PZB on (aux squares), PZB mode set in the cab
  • Lights (AUTO BRK)
  • Fahrstufenschalter at 0 before moving the reverser

Cleared to depart

  • Check the signal and PZB
  • Richtungsschalter to Forward
  • Führerbremsventil to Running, wait for the brakes to release
  • Zusatzbremse to Release (flap lever away)
  • Fahrstufenschalter up step by step, watch the ammeter
  • Acknowledge SiFa with the gear lever, PZB with the ENG switches
  • Brake: Führerbremsventil in steps, Abschluss holds
