Class 378

Cab setup

  • Insert master key (PARK BRK)
  • Reverser to neutral
  • Check AWS and DSD are normal (aux squares)
  • Set headlights / tail lights
  • Open doors

Cleared to depart

  • Close doors
  • Wait for guard buzzer
  • Check signal
  • Reverser to forward
  • Handle through Off to P1, then power as needed
