Class 52

Cab setup

  • Battery switch closed in the cab
  • Master key and brake key in (PARK BRK up)
  • Start engine A (right throttle button) and engine B (round aux)
  • AWS isolation light out, DSD fuse in
  • Headlights on (AUTO BRK)
  • Release the handbrake in the cab

Cleared to depart

  • Check the signal
  • Train brake to Running, wait for the pipe to charge
  • Reverser to Forward
  • Loco brake to Release (flap lever away)
  • Power controller to On, then open up slowly
  • Acknowledge AWS with the gear lever
  • Power controller to Off before moving the reverser back
