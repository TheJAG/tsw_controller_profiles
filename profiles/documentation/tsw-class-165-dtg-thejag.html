Class 165

Cab setup

  • Master key in (PARK BRK)
  • Start the engine (right throttle button)
  • Reverser from Off to Neutral
  • Check the TPWS / AWS and DSD isolation lights are out; DRA in the cab
  • Headlights to Day
  • Open doors (RUD TRIM)

Cleared to depart

  • Close doors, wait for the guard buzzer (round aux)
  • Check the signal and release the DRA
  • Reverser to Forward
  • Handle from Full service through Off to P1
  • Notch up to P7 as speed rises
  • Acknowledge AWS with the gear lever
