Class 20

Cab setup

  • PARK BRK up: master key in; brake selector (vacuum / air, goods / passenger) in the cab
  • Start the engine (right throttle button)
  • Reverser from Off through Engine only to Forward: the power handle only moves then
  • Check the AWS isolation light is out
  • Lights to Front markers
  • Loco brake at Full, vacuum brake at Full (parked)

Cleared to depart

  • Check the signal; release the handbrake in the cab
  • Vacuum brake to Running, loco brake to Release
  • Power handle to On, then into the power zone
  • Acknowledge AWS with the gear lever
  • Brake: power Off, vacuum brake towards Full; Emergency at the far end
  • Change direction: power Off first, then the reverser
