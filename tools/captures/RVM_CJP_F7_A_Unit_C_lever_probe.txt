  INTERLOCKS LAG ONE EVENT. The game evaluates the throttle / transition / reverser interlocks with the state from BEFORE the last change of the other lever.
  After a single API set TransitionLever Off -> SP the throttle stays locked; after SP -> Off the throttle still takes one move (then locks).
  Likewise after Throttle N3 -> Idle in one set, TransitionLever refuses Braking -> Off and Reverser refuses Forward -> Neutral.
  A second set to a slightly different value of the lever just moved (TransitionLever 0.41 after 0.4, 0.21 after 0.2, 0.01 after 0; Throttle 0.12 after 0.11) is a change
  event that snaps back to the same notch and refreshes the interlock; then the behaviour is clean (log below). A set to the identical value is no event (no refresh).
  This is why the sweep (and the first probes) saw the throttle at one notch.
