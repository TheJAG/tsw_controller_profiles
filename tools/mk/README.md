# Profile build scripts

One script per train, run after `draft_profile.js` has written the base profile: `node tools/mk/mk147.js profiles/<file>.json [store.steampowered.com/app/<id>]`. The script replaces the `controls` block and the rail classes of that profile with the train's TCA layout (lever geometry, bands, buttons) and writes the manual data file `tools/manual/trains/<slug>.json`. Copy the nearest relative for a new train (mk147 = TRAXX 3 combined handle, mk185 / mk146 = TRAXX 2 with separate Fahrschalter, mk101 = German loco base, mk805 / mk801 = Hitachi units, mk350 = Desiro, mk43 = BR diesel, mkf125 = US combined throttle / dynamic handle, mkf59ph = the same with a -1..1 EMD handle, mkmp36ml = Metrolink MP36PH-3C on the F59PHR nodes, mkm3a = Metro-North M3a on the LIRR M3 desk, mk750 = Czech loco with handwheel and DAKO BS2 valve, mk843 = Czech railcar with a spring combined handle, mkm7a = Metro-North M7a on the LIRR M7 controller, mkm8 = Metro-North M8, mkalp45 = NJ Transit ALP-45DP, a notched automatic brake, mkalp46 = the same on _F/_B nodes with {SIDE:F:B}, mkarrow3 = EMU controller with the direction built in, mkes44ac = Skyhook GE ES44AC with a trailing-unit set-up, mkgp38ns = NS GP38-2 on the CSX stand, mksfc40 = Santa Fe C40-8W on the CSX C40-8W nodes) and adjust the node names from the capture. They used to live in the session scratchpads; since 2026-10-11 they are committed here.

## New scripts use `lib.js` (since 2026-10-12)

`lib.js` holds what every script used to copy: `load` / `save` / `writeManual`, `pakClasses(re)`, `capture` / `lever`, and the assignment helpers `mom`, `tog`, `togA`, `momA`, `pair`, `key`, `set`, `rel`. A new script imports them and holds only the train's own data: node names, values, lever bands, the control layout and the manual data. When copying an older script as the starting point, replace its helper block with the `require('./lib')` line. Leave the older scripts as they are: their profiles are cab-tested.

`load` refuses a missing or `DLCID` store link, and `node tools/check.js` (run by `build_release.js` and `render_manual.js`) fails on node names that are not in the capture and on a cab photo shared with another train. Both were copy leftovers before.
